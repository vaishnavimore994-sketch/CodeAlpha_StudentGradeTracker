# Student Grade Tracker

A Java program to input and manage student grades, built as part of the CodeAlpha Java Programming Internship (Task 1).

## Features
- Input and manage student grades
- Calculate average, highest, and lowest scores
- Store and manage data using arrays/ArrayLists
- Display a summary report of all students
- Console-based interface

## How to Run
1. Clone this repository
2. Compile: `javac StudentGradeTracker.java`
3. Run: `java StudentGradeTracker`
